The correlation on this page is CIRCULAR and must not be read as validity. The same person wrote the transcripts and the lexicon, so the transcripts contain the cues the lexicon looks for. What is demonstrated is that the pipeline is internally consistent and that the evaluation protocol is sound — not that the measure tracks clinical empathy.

What is being measured

Not "nice words". Clinical empathy research measures specific behaviours, and the lexicon is organised by the behaviour each cue signals, following the structure of established consultation-coding schemes — the Empathic Communication Coding System and the socio-emotional categories of the Roter Interaction Analysis System.

Scores are length-normalised per 100 tokens. A long consultation accumulates cue hits simply by being long, so an unnormalised count measures duration.

The lexicon

CategoryCuesBehaviour it indexes
acknowledgement14Naming or reflecting the patient's emotion back to them
validation14Explicit emotional support; normalising the experience
exploration12Inviting the patient to say more — the strongest behavioural signal
partnership11Shared decision-making; checking understanding
warmth9Weak individually, real in aggregate
dismissal13Negative weights. Without these, a curt consultation scores as neutral

Why dismissal carries negative weight

Empathy is not only the presence of warmth. A lexicon with no negative category scores a curt, blame-shifting consultation as merely neutral, which is exactly the case a quality measure needs to catch. Removing the dismissal cues drops the correlation from +0.946 to +0.933.

This correlation is circular

One person wrote the transcripts, the ratings and the lexicon. The transcripts therefore contain the cues the lexicon looks for, and the ratings reflect the same intuitions that set the weights. A correlation of +0.946 under these conditions measures internal consistency, not validity.

What the number does establish is narrower and still worth having: the pipeline runs end to end, the evaluation protocol is honest (leave-one-out, no fold reuse), and the features separate the cases they were designed to separate. Validity requires a collected corpus with ratings from clinicians who did not build the measure — and inter-rater agreement reported alongside.

Reproduce it

python -m pytest tests/ -q

What this does not establish

  • No validity evidence. The correlation is circular, as set out above. Nothing here shows the measure tracks clinical empathy.
  • Sixteen authored transcripts is not a corpus. Leave-one-out on sixteen items has error bars wide enough to contain most values you might care about.
  • No inter-rater agreement, because there is one rater.
  • No patient outcome is attached to any transcript, so nothing here speaks to whether the measured behaviour helps anyone.
  • The Mandarin cues are a smaller set than the English ones and were written by the same person; the near-identical cross-language correlation reflects that symmetry in authoring, not demonstrated cross-lingual validity.

The predecessor project trained on data synthesised at runtime and evaluated on the same generator. This replaces that with a held-out protocol and an explicit statement of what is still missing. The remaining gap is a real corpus.
